AK Design System

Ein modernes SCSS-basiertes Design System mit ak- prefixed Klassen, responsivem Design und umfassendem Theming-Support.

Modular

Aufgebaut mit modernem SCSS @use/@forward für optimale Performance.

Responsive

Mobile-first Design mit flexiblen Grid-Systemen und adaptiven Komponenten.

Theming

Dark/Light Theme Support mit CSS Custom Properties.

CSS Einbindung

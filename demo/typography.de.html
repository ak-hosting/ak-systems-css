Fließtext

Absatzgrößen

Großer Text. Wird für Einleitungen oder Lead-Absätze verwendet, um Aufmerksamkeit zu erregen.

.ak-text-lg

Basis-Text. Die Standardgröße für den Großteil des Inhalts auf der Seite.

.ak-text-base

Kleiner Text. Oft für sekundäre Informationen, Bildunterschriften oder Hilfstexte verwendet.

.ak-text-sm

Extra kleiner Text. Wird für das Kleingedruckte oder Urheberrechtshinweise verwendet.

.ak-text-xs

Inline-Elemente

Sie können fetten Text, kursiven Text oder unterstrichenen Text verwenden.

Links können mit der Klasse .ak-link gestaltet werden.

Inline-Code-Schnipsel wie const x = 1; werden mit .ak-code gestylt.

Markieren Sie Text für Hervorhebungen wichtiger Teile.
